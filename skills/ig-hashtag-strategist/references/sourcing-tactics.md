# Tactiques pour trouver des hashtags

Comment `ig-hashtag-strategist` trouve et calibre les tags candidats. À lire
avec le modèle complet dans `../../../references/hashtag-strategy.md`.

## Trouver les tags de niche (les chevaux de trait)

Les tags de niche (moins de 50k posts) sont là où un petit ou moyen compte se
classe et reste visible pendant des heures. Sources :

- **Combiner deux mots :** sujet + audience (`#notionpourfreelances`), sujet +
  format (`#designdecarrousel`), sujet + style (`#photoculinairemoche`).
- **Les noms de communauté :** comment les gens de ton monde exact
  s'appellent entre eux (`#saasbootstrappe`, `#argentiquecommunaute`).
- **Les créatrices que tu admires :** les tags plus petits dans lesquels elles
  se classent vraiment (pas les géants de leur première ligne).
- **L'autocomplétion de la recherche Instagram :** tape le sujet et lis les
  tags suggérés avec leur nombre de posts ; ceux sous ~50k sont tes
  emplacements de niche.

## Trouver les tags intermédiaires (les prolongateurs)

Les tags intermédiaires (50k à 500k) nomment un sous-sujet reconnaissable :
`#strategiedecontenu`, `#indiehacker`, `#photographieargentique`. Ils étendent
la portée vers une audience chaude sans être imprenables. Un ou deux par post.

## L'emplacement large (optionnel)

Les tags larges (500k et plus) sont des mots courants isolés : `#marketing`,
`#fitness`, `#cuisine`. Ils classent pendant quelques minutes, donc
traite-les comme une étiquette de catégorie. Au plus un, et seulement s'il
colle vraiment. Mieux vaut le sauter que le forcer.

## Calibrer sans API

Aucune API ne donne le nombre de posts d'un tag. Calibre avec :

1. **L'heuristique de spécificité :** plus c'est précis et combiné, plus
   c'est niche. Un mot courant isolé est large.
2. **La vérification dans l'app :** dis à l'utilisatrice de regarder le nombre
   qu'Instagram affiche dans la recherche pour les tags à la limite.

## Tags à écarter à vue

- Les tags de ferme à engagement : `#follow4follow`, `#like4like`, `#followforfollowback`.
- Tout ce qui alterne entre statut signalé et banni (les tags génériques qui sentent le spam).
- Les tags populaires mais hors sujet. Un décalage entraîne le moteur de
  recommandation à montrer le post à la mauvaise audience, ce qui baisse le
  taux d'engagement et la portée.

## Rotation

Ne réutilise pas un seul bloc de 5 tags sur chaque post. Des jeux identiques
sur beaucoup de posts sentent l'automatisation. Fais tourner les tags de niche
pour coller au sujet précis de chaque post ; les emplacements intermédiaire et
large peuvent rester plus stables à l'intérieur d'un pilier de contenu.
